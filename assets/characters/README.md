# Neuro Bob+ — 12 mascottes PNG

12 poses réutilisables, chacune dans son propre fichier PNG **512 × 512 px, fond transparent**. Les fichiers proviennent de la planche de mascottes produite pour le projet, puis isolés en 12 images transparentes.

| Pose | Fichier | Usage suggéré |
|---|---|---|
| 1 | `01-salut.png` | Salue de la main |
| 2 | `02-orientation.png` | Montre une direction |
| 3 | `03-reflexion.png` | Réfléchit |
| 4 | `04-ecoute.png` | Écoute |
| 5 | `05-celebration.png` | Célèbre |
| 6 | `06-accueil.png` | Accueille |
| 7 | `07-presentation.png` | Présente un graphique |
| 8 | `08-lecture.png` | Lit un livre |
| 9 | `09-exploration.png` | Explore avec une loupe |
| 10 | `10-empathie.png` | Tient un cœur |
| 11 | `11-validation.png` | Valide une idée |
| 12 | `12-conversation.png` | Converse |

- Le fichier `manifest.json` décrit les 12 variantes.
- Un visuel de référence pour la composition UI se trouve dans `design/reference-interface-validee.jpg`.
- Ces images sont conçues pour être utilisées dans l'interface : conserver les proportions et ne pas ajouter de fond opaque dans les fichiers.
- Les éléments ne sont pas des composants d'interface interactifs ; les illustrations doivent rester décoratives lorsqu'elles sont associées à un texte équivalent.
