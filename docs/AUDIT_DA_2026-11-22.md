## 2. Direction artistique cible

**Principe :** *une marque calme, un seul accent, un seul personnage.* Fond clair uni, surfaces blanches, bleu marque pour l'action, jaune réservé au logo et à l'état actif. La mascotte porte l'émotion, le reste de l'interface s'efface.

### 2.2 Typographie
- **Police :** Inter variable **auto-hébergée** (`assets/fonts/InterVariable.woff2`, `font-display:swap`), repli `system-ui`. Pas d'appel à Google Fonts depuis un outil interne (évite une fuite d'adresse IP vers un tiers). Pas de police « spéciale dyslexie » par défaut (preuves faibles) : le réglage « Texte plus grand » existe déjà.
- **Graisses :** 400 / 600 / 700 uniquement.
- **Échelle (rem) :** xs .75 (kicker, métadonnées : **minimum absolu**) · sm .875 (texte de carte) · md 1 (paragraphes) · lg 1.125 (accroche) · xl 1.375 (titre de carte ou panneau) · 2xl 1.75 (H2) · 3xl 2.25 (H1 de page) · display `clamp(2.25rem,1.5rem+2.2vw,3.25rem)` (hero).
- Interlignage 1,6 (corps), 1,15 (titres) ; `letter-spacing:-.02em` maximum sur les titres ; paragraphes ≤ 65 ch.

### 2.3 Formes, ombres, espacements
- **Rayons :** 8 (chips, petits champs) · 12 (boutons, items de menu, pastilles d'icône) · 16 (cartes) · 24 (hero, panneaux) · 999 (pills de filtre). Plus de 15/17/19/21/22/23/28/40.
- **Ombres :** deux niveaux seulement. `--sh-1` (repos) `0 1px 2px rgba(19,37,79,.06), 0 2px 8px rgba(19,37,79,.05)` ; `--sh-2` (survol) `0 2px 4px rgba(19,37,79,.06), 0 8px 24px rgba(19,37,79,.10)`.
- **Espacements :** base 4 : 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64.

### 2.5 Mascotte : règles d'usage
1. **Un seul robot par écran**, jamais en simple ornement répété ; jamais deux poses identiques à moins de 3 s d'intervalle (d'où intro = `01`, hero = `06`).
2. **Toujours ancré** : soit le buste coupé sur un bord de panneau (`overflow:hidden`, la coupe à la taille tombe sur le bord), soit en avatar recadré. Jamais flottant au milieu d'une forme.
3. **Immobile par défaut.** Seule animation autorisée : l'intro (≤ 2,4 s, une fois).
4. Les traits jaunes appartiennent au PNG : **aucun éclat ajouté en CSS**.
5. Toujours `alt=""` + `aria-hidden` sur le conteneur quand l'image est décorative.

**Tâche asset recommandée (hors CSS) :** générer des versions rognées (`assets/characters/trim/`, boîte utile + 4 % de marge) et des avatars tête 128×128. Script (à lancer par l'agent qui édite le dépôt, Pillow) :
```python
from PIL import Image; import glob, os
os.makedirs("assets/characters/trim", exist_ok=True)
for f in glob.glob("assets/characters/*.png"):
    im = Image.open(f); x0,y0,x1,y1 = im.getbbox(); m = 20
    im.crop((x0-m, y0-m, x1+m, y1+m)).save(f.replace("characters/","characters/trim/"), optimize=True)
    head = im.crop((x0, y0-6, x1, y0 + (x1-x0) - 6)).resize((128,128), Image.LANCZOS)
    head.save(f.replace("characters/","characters/trim/").replace(".png","-avatar.png"), optimize=True)
```
(Les corrections CSS ci-dessous fonctionnent **avec les PNG actuels** ; si on passe aux PNG rognés, supprimer le `translate:0 22%` et la marge négative mobile.)

### 4.1 Storyboard (2,4 s au total, passable à tout moment)

### 4.2 Règles
- **Une fois par session** : `sessionStorage["nb-intro-seen"]`, lecture et écriture dans `try/catch`. Si le stockage est indisponible, **pas d'intro** (sinon elle se rejouerait à chaque rechargement).
- **Jamais** si `prefers-reduced-motion: reduce`, ni si l'utilisateur a activé « Réduire les animations » ou « Interface apaisée » (lecture de `localStorage["neuro-bob-display"]`, la clé déjà utilisée par `app.js`), avec en plus des filets CSS.
- **Passable** : toute touche (Échap, Tab, Entrée…), clic ou toucher. Pas de `preventDefault` : le premier Tab passe l'intro **et** atteint le lien d'évitement. Pendant le fondu, l'overlay garde les événements de pointeur : le clic de saut n'active aucun bouton situé dessous.
- **Accessibilité** : overlay `aria-hidden="true"`, aucun élément focusable dedans (pas de piège au focus) ; le contenu de la page reste dans l'arbre d'accessibilité pendant 2,4 s (un lecteur d'écran lit la page normalement) ; durée < 5 s (2.2.2) ; aucun clignotement (2.3.1).
- Piège évité et constaté pendant le test : **ne pas** nommer la classe de `<html>` comme celle de l'overlay (`.nb-intro { display:none }` masquait `<html class="nb-intro">` entier). D'où `html.nb-intro-play` + `.nb-intro-overlay`.

**d) `intro.js`**
```js
/* Neuro Bob+ — animation d'ouverture. Script classique, chargé de façon bloquante
   dans <head> (≈1 Ko) pour poser la classe avant le premier rendu : pas de flash. */
(function () {
  var root = document.documentElement;
  var play = false;
  try {
    var seen = sessionStorage.getItem("nb-intro-seen");
    var prefs = JSON.parse(localStorage.getItem("neuro-bob-display") || "{}");
    var reduce = window.matchMedia && window.matchMedia("(prefers-reduced-motion: reduce)").matches;
    play = !seen && !reduce && !prefs.motion && !prefs.simple;
    if (play) sessionStorage.setItem("nb-intro-seen", "1");
  } catch (e) {
    play = false; /* stockage indisponible : on ne rejoue pas l'intro à chaque page */
  }
  if (!play) return;
  root.classList.add("nb-intro-play");

  var ended = false;
  var timer = setTimeout(end, 2100); /* + 0,3 s de fondu = 2,4 s */
  function end() {
    if (ended) return;
    ended = true;
    clearTimeout(timer);
    document.removeEventListener("keydown", end, true);
    document.removeEventListener("pointerdown", end, true);
    root.classList.add("nb-intro-out");
    setTimeout(function () {
      root.classList.remove("nb-intro-play", "nb-intro-out");
      var el = document.getElementById("nb-intro");
      if (el) el.remove();
    }, 300);
  }
  /* Toute touche (Échap, Tab, Entrée…) passe l'intro ; on n'appelle pas
     preventDefault : Tab atteint donc normalement le lien d'évitement. */
  document.addEventListener("keydown", end, true);
  /* Clic / toucher : l'overlay garde pointer-events pendant le fondu,
     le clic de saut ne déclenche donc aucun bouton situé dessous. */
  document.addEventListener("pointerdown", end, true);
})();
```
